# 🎯 Hangman Game (Python)

This project is a simple **text-based Hangman game** developed using Python.
The player guesses a hidden word letter by letter within a limited number of attempts.

## 📌 Features
- Predefined list of words
- Random word selection
- Maximum 6 incorrect attempts
- Console-based interaction
- Beginner-friendly code

## 🛠️ Technologies Used
- Python
- random module
- Loops, conditionals, lists, and strings

## ▶️ How to Run
```bash
python hangman_game.py
